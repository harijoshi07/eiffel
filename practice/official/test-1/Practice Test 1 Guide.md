## Best first attempt

[Launch Practice Test 1 on ETS](https://www.ets.org/toefl/test-takers/ibt/prepare/sample-test-jan-2026-1.html)

Use the interactive version for authentic audio and prompt delivery. Use the local PDF only if the interactive version is unavailable.

## Setup

- [ ] Quiet room and headphones
- [ ] Keyboard
- [ ] Scratch paper and pencil
- [ ] Voice recorder if the platform does not retain Speaking responses
- [ ] Notifications disabled
- [ ] Approximately two uninterrupted hours

## Section targets

| Section | Published base time |
|---|---:|
| Reading | about 30 min |
| Listening | about 29 min |
| Writing | about 23 min |
| Speaking | about 8 min |

Follow the on-screen clock in the interactive version. The times above are planning estimates, not permission to override the test interface.

## Rules

1. Do not pause or replay audio.
2. Do not use a dictionary, grammar checker, or outside help.
3. Do not open transcripts or keys.
4. Complete sections in order.
5. Record all Writing and Speaking responses.
6. If one item is difficult, answer and continue.

## Review sequence

1. Check Reading against [[answer-keys/Reading Key.pdf]].
2. Check Listening against [[answer-keys/Listening Key.pdf]].
3. Only now read the Listening transcript to locate missed evidence.
4. Check Build a Sentence against [[answer-keys/Writing Key.pdf]].
5. Review the email and discussion response with [[Writing Playbook]].
6. Review Speaking recordings with [[Speaking Playbook]].
7. Enter no more than five recurring patterns in [[Progress Tracker]].
