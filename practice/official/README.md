# Official ETS Practice Tests

Both ETS full-length samples for the TOEFL iBT format used from January 21, 2026 are stored here.

| Test | Best use | Interactive test | Local guide |
|---|---|---|---|
| Practice Test 1 | Day 1 baseline | [Launch through ETS](https://www.ets.org/toefl/test-takers/ibt/prepare/sample-test-jan-2026-1.html) | [[Practice Test 1 Guide]] |
| Practice Test 2 | Day 6 final simulation | [Launch through ETS](https://www.ets.org/toefl/test-takers/ibt/prepare/sample-test-jan-2026-2.html) | [[Practice Test 2 Guide]] |

## Which version should I use?

### Interactive ETS version

Use this for the first full attempt. It provides the most realistic delivery, especially for:

- Listening audio;
- Listen and Repeat prompts;
- the Interview task;
- on-screen timing and navigation.

The ETS launch page asks for a brief form before opening the test.

### Local PDF version

Use the PDFs for:

- Reading and Writing drills;
- reviewing Listening transcripts after an audio attempt;
- reviewing Speaking prompts after recording;
- checking official Reading, Listening, and sentence-building answers.

The PDF explicitly states that it is adapted for paper-format usability and is not an exact replica of the live test.

## Folder design

Each test contains:

```text
ETS Practice Test N.pdf    unchanged official PDF
Practice Test N Guide.md   simulation and review protocol
Practice Test N Answer Sheet.md
                           spoiler-free response sheet
questions/                 section-only PDFs
answer-keys/               separate keys; do not open early
```

## Spoiler rule

Do not open `answer-keys/` or read Listening/Speaking transcripts before completing the corresponding interactive section. Once seen, these tests cannot provide a clean baseline again.

## Recommended sequence

1. **Day 1:** Practice Test 1 as a diagnostic.
2. Review it completely and record error causes in [[Progress Tracker]].
3. Train with the section playbooks during Days 2–5.
4. **Day 6:** Practice Test 2 under uninterrupted test conditions.
5. Use Day 7 only for targeted correction and rest.
